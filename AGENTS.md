# AGENTS.md — руководство для AI-агентов

## О проекте

Учебный проект (вуз, курс по информационным/управляющим системам). Репозиторий содержит документацию, а не исходный код.

- **WMap** — платформа совместного планирования путешествий: интерактивная карта, маршруты, рейтинги, отзывы, социальная сеть пользователей.
- Студенческий масштаб: бюджет 0, нагрузка ~0.5 RPS — использовать только бесплатные решения.

## Структура репозитория

| Файл | Содержимое |
|---|---|
| `DOCS.md` | Документация платформы WMap: концепция, модули, архитектура, API, схема БД (SQL), экраны, фазы разработки, стек технологий |
| `AGENTS.md` | Этот файл: инструкции для агентов |

## Конвенции

- **Язык документов — русский.** Весь текст и комментарии пишутся на русском.
- **Формат — Markdown.** Соблюдать существующую структуру заголовков (`#`, `##`, `###`), таблиц и код-блоков.
- Код-блоки для схем — ASCII-арт; при правках сохранять выравнивание рамок и стрелок.
- Исправлять грамматику/опечатки в существующих файлах можно, но без изменения содержания.
- Коммиты и push выполнять только по явному запросу пользователя.
- Не создавать новые файлы и документацию без явного запроса.

## Текущее состояние проекта

Постоянного кода нет — только планирование. При появлении исходного кода следовать рекомендациям из `DOCS.md` (разделы «Архитектура» и «Стек технологий»): React + Vite, FastAPI (Python), SQLite, Leaflet + OpenStreetMap — только бесплатные сервисы.

## Как работать

1. Перед изменениями читать затронутые `.md`-файлы целиком.
2. После любых правок проверять рендеринг Markdown и целостность таблиц/схем.
3. Если задача выходит за рамки документации — уточнять у пользователя требования перед началом работы.
